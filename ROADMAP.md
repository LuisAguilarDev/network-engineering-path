# CCNA 200-301 Roadmap

Topics based on the CCNA 200-301 v1.1 exam blueprint.
Always verify against the current [official exam topics](https://learningnetwork.cisco.com/s/ccna-exam-topics).

Legend: `[ ]` not started · `[~]` in progress · `[x]` done

## 0. Base Knowledge (not an exam domain)

- [x] OSI and TCP/IP models (layers, PDUs, encapsulation, devices per layer)

## 1. Network Fundamentals (20%)

- [~] Network components (routers, L2/L3 switches, firewalls, APs, WLCs, endpoints, servers)
- [ ] Network topology architectures (2-tier, 3-tier, spine-leaf, WAN, SOHO, cloud)
- [ ] Physical interfaces and cabling (copper, fiber, PoE)
- [ ] Interface and cable issues (collisions, errors, duplex, speed)
- [ ] TCP vs UDP
- [ ] IPv4 addressing and subnetting
- [ ] Private IPv4 addressing
- [ ] IPv6 addressing and prefixes (unicast, anycast, multicast, EUI-64)
- [ ] Verify IP parameters on client OS (Windows, macOS, Linux)
- [ ] Wireless principles (channels, SSID, RF, encryption)
- [ ] Virtualization fundamentals (VMs, containers, VRFs)
- [~] Switching concepts (MAC learning, frame flooding, MAC table)

## 2. Network Access (20%)

- [~] VLANs (access ports, data and voice VLANs, inter-VLAN connectivity)
- [~] Interswitch connectivity (802.1Q trunks, native VLAN)
- [ ] Layer 2 discovery protocols (CDP, LLDP)
- [ ] EtherChannel (LACP)
- [ ] Rapid PVST+ Spanning Tree (root bridge, port roles/states, PortFast)
- [ ] Wireless architectures and AP modes
- [ ] WLAN physical infrastructure connections (AP, WLC, LAG)
- [ ] AP and WLC management access (Telnet, SSH, HTTP/S, console, TACACS+/RADIUS)
- [ ] WLAN GUI configuration (WPA2 PSK)

## 3. IP Connectivity (25%)

- [ ] Components of a routing table
- [ ] Router forwarding decisions (longest prefix match, AD, metric)
- [ ] IPv4 and IPv6 static routing (default, network, host, floating)
- [ ] Single-area OSPFv2 (neighbors, point-to-point, broadcast, DR/BDR, router ID)
- [ ] First Hop Redundancy Protocols (HSRP concepts)

## 4. IP Services (10%)

- [ ] Inside source NAT (static and pools)
- [ ] NTP client/server
- [ ] DHCP and DNS roles
- [ ] SNMP
- [ ] Syslog (facilities and levels)
- [ ] DHCP client and relay
- [ ] QoS concepts (classification, marking, queuing, policing, shaping)
- [ ] SSH remote access
- [ ] TFTP/FTP

## 5. Security Fundamentals (15%)

- [ ] Security concepts (threats, vulnerabilities, exploits, mitigation)
- [ ] Security program elements (user awareness, training, physical access)
- [ ] Device access control with local passwords
- [ ] Password policies, MFA, certificates, biometrics
- [ ] IPsec remote access and site-to-site VPNs
- [ ] Access control lists (standard and extended)
- [ ] Layer 2 security (DHCP snooping, Dynamic ARP Inspection, port security)
- [ ] AAA concepts (authentication, authorization, accounting)
- [ ] Wireless security protocols (WPA, WPA2, WPA3)

## 6. Automation and Programmability (10%)

- [ ] Impact of automation on network management
- [ ] Traditional vs controller-based networking
- [ ] SDN architectures (overlay, underlay, fabric, northbound/southbound APIs)
- [ ] AI/ML in network operations
- [ ] REST APIs (CRUD, HTTP verbs, data encoding)
- [ ] Configuration management (Ansible, Terraform)
- [ ] JSON-encoded data
