# Labs

Hands-on labs that prove practical skills.

## How to create a lab

1. Copy `_template/` to a new folder named `NNN-short-name` (e.g. `001-vlan-trunking`)
2. Fill in the README sections
3. Save the topology file, final device configs, and screenshots
